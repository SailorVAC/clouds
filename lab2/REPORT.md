# Лабораторная работа 2

Решение: `SPSPublic-main/SPS.Student/MySystemPolicy.cs`; стратегия подключена в `SPS.Runner/Program.cs`.

Кэш возвращает записи с запасом по свежести и объединяет близкие по времени загрузки; при нехватке памяти удаляются менее востребованные записи с учётом размера. API выбирается по нагрузке и скорости. Задания упорядочиваются по отношению цены к оценке работы, а при длительном отсутствии heartbeat возвращаются в очередь. Для RPC используются ограниченные повторы с задержкой. Число экземпляров ограничено доступными вычислительными единицами.

Проверка: .NET 8, Release, открытый сценарий, seed 42. Базовая стратегия: Profit 206,2; новая: 507,4. Это результат одного открытого сценария, а не гарантия результата на закрытых сценариях.

Запуск: `dotnet run --project SPSPublic-main/SPS.Runner -c Release -- --seed 42`.
