# Лабораторная работа 3

Решатель `DC.Compute/ParallelPowSolver.cs` подключён в приложении как **Parallel workers**. Фиксированное число фоновых потоков независимо выбирает следующую свободную задачу. У каждого потока свой экземпляр SHA-256 и свои буферы. Внутри поиска нет общей блокировки; прогресс и телеметрия обновляются вне каждого хеша или пакетами. Поддерживается отмена.

Проверка: Release, .NET 8, seed `000123`, сложность 18, включена телеметрия; все 100 решений дополнительно проверены независимым вычислением SHA-256. Выполнено 20 475 555 хешей в каждом запуске.

| Реализация | Воркеры | Время, с |
|---|---:|---:|
| Baseline | 1 | 2,454 |
| Baseline | 4 | 1,348 |
| Parallel workers | 1 | 1,505 |
| Parallel workers | 4 | 0,397 |

Для новой реализации ускорение четырёх воркеров составило примерно 3,79, эффективность — 94,8%. Это единичные измерения на текущем компьютере, а не стабильная оценка производительности. На других системах результаты будут отличаться; масштабирование ограничивается доступными ядрами, накладными расходами и неравномерной длительностью задач.

Запуск: `dotnet run --project DC.App -c Release`. Выберите **Parallel workers**, выполните запуск с одним и несколькими воркерами и нажмите **Validate All Results**.
